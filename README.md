# Nexora AI

Nexora AI is a modern web application built with **Next.js**, **TypeScript**, and **Tailwind CSS**, designed for seamless integration with automation services and external APIs.

---

## 🚀 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Backend Integrations:** Google Apps Script (`/google-apps-script`)
- **Deployment:** [Vercel](https://vercel.com)

---

## 📁 Repository Structure

```text
